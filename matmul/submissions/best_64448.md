## Method

Keep the 64,456 program's two column panels **[6,10]**, row groups
**[4,4,4,4] / [5,5,6]**, and respective one-term/two-term contraction chunks.
Stage both operands and immediately consume each product into its output
accumulator. The changes are:

- Start the first two narrow-panel row groups at contraction indices **3** and
  **11**, wrapping modulo 16; start the last wide-panel row group at **4**.
- Start column traversal descending in the first and last wide-panel row groups;
  continue alternating column direction after every contraction chunk.
- Retain persistent B captures only for columns **8–15**, independently of the
  panel boundary at column 6.

Every output still consumes all 16 products `A[i,k]*B[k,j]` exactly once.
There are 128 B captures and 256 captured-value reloads. Column 7 now reloads
its original B values in all three wide-panel row groups. This removes sixteen
copies relative to the parent, while changing input and accumulator lifetimes.

Use the repository's weighted lifetime-chain initializer, reparse the physical
IR, and run pair allocation for two rounds with seed 0 and ties disabled,
followed by five rounds with seed 11 and neutral moves enabled. Each pair-tier
flow is exact; the complete allocation procedure remains heuristic. The second
pass preserves score 64,448 while changing its distribution among read categories.

The measured gain is **eight points below 64,456**: copy cost rises 50,
multiplication is unchanged, addition falls 7 and exit falls 51. These costs
belong to the combined change and cannot be assigned independently to its
individual mutations.
