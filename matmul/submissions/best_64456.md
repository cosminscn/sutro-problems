# Matrix Multiplication

**Author:** [@cosminscn](https://github.com/cosminscn) and Codex<br>
**Date:** 2026-09-04 (UTC)<br>
**Problem:** 16x16 matmul<br>
**Cost:** 64,456

## Method

Retain the 64,475 program's geometry and arithmetic order, but capture B inputs
only in columns **7–15**. Column 6 still belongs to the wide panel; it now reads
its original B inputs separately for each of the three wide-panel row groups.
This removes sixteen persistent captures and thirty-two captured-value reloads,
while adding thirty-two original-input reloads: sixteen fewer copies overall.

The two column panels are **[6,10]**. Columns 0–5 use row groups **4+4+4+4**
and one-term contraction chunks; columns 6–15 use **5+5+6** and two-term chunks.
Visit the narrow panel first. Reverse column traversal after each contraction
chunk within each tile. Stage A at first use and reuse it across columns;
stage B per column and reuse it across rows. Consume old C through each product
immediately, so a two-term update is `(C + A[i,k]*B[k,j]) + A[i,k+1]*B[k+1,j]`.
There are 144 B captures and 288 captured-value reloads.

Initialize addresses with the repository's weighted lifetime-chain allocator,
reparse its physical IR, then run pair allocation for two rounds with seed 0
and ties disabled, followed by five rounds with seed 11 and neutral moves
enabled. Each pair-tier flow is exact; the complete allocation procedure is
heuristic. Discovery used native graph preparation, while portable replay
uses the reference Python graph preparation, identical RNG and OR-Tools solver.

The measured gain is **19 points below 64,475**. Copy cost falls 57,
multiplication cost is unchanged, addition rises 10 and exit rises 28. These
costs describe one fully verified program. The result comes from selecting
which B values to retain and reallocating the resulting lifetimes; a change
to output tile geometry was not required.

All 512 inputs are present at entry. Every source read and all 256 common-exit

semantics. No optimality claim is made, and fixed-trace bounds for previous
programs do not transfer to this trace.

The standard-library verifier checks all 256 outputs with the unchanged
official scorer and independent exact noncommutative proof, along with the
frozen artifact hash, operation counts and category costs. Both focused tests
passed with site packages disabled. Fresh portable replay generates the whole
trace from literal loops, checks four stage hashes and both accepted-history
hashes, and matches the submitted bytes. Recorded runtime was 6.84 seconds
with Python 3.12.14, NumPy 2.3.5 and OR-Tools 9.15.6755. Replay needs no research
workspace, external seed, native library or compiler.

The candidate was found in a finite guillotine-tree search that also permitted
capture-threshold mutations. The winning mutation only changes threshold 6
to 7. The literal portable generator keeps that single change explicit and
reuses unchanged initialization and allocation helpers from the 64,829 package.

including the campaign's connection to Juraj Selep's PR #50, are preserved in
the preceding reports.
